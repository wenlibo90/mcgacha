# 麦门抽卡机 McGacha

> 今天吃什么？抽一张就知道了。
> 基于麦当劳 MCP 的创意 Skill：抽卡点餐 × 徽章图鉴 × 麦门DNA × 终端下单

一个把"吃麦当劳"变成收集游戏的 AI Skill。接入麦当劳官方 MCP 真实数据（在售菜单、实时价格、优惠券、附近门店、历史订单、营养成分），让 AI 帮你抽卡决定今天吃什么，顺便把每一顿麦当劳都变成可收集、可晒图、可回顾的仪式感。

## 四大玩法

### 1. 今日抽卡 · 吃什么不用想
对 AI 说一句"今天吃什么"，抽一张麦门卡牌：
- 按当前时段（早餐/正餐/夜宵）从**真实在售菜单**随机推荐套餐或单品
- 卡牌附带**真实价格、热量、蛋白质**等营养数据
- 不满意就"再抽一张"，抽到满意直接一键下单（可选）
- 抽卡同时自动为你**一键领取可领优惠券**
- 附上**附近门店**列表（距离、营业状态），卡牌在哪吃一目了然

### 2. 徽章图鉴 · 麦门年度故事
每一顿麦当劳都是一枚徽章：
- 读取你的**真实历史订单**，把吃过的单品铸成徽章图鉴（巨无霸、麦旋风、板烧……集齐召唤神龙）
- 生成「我和麦当劳的年度故事」回顾页：第一次相遇的门店、点过最多次的最爱、深夜食堂时刻、年度消费与营养总览
- 图鉴与故事页均为本地生成的静态 HTML，零依赖、可直接保存分享

### 3. 麦门DNA
仿基因检测风格的趣味报告：
- **血统成分分析**：板烧血统、穷鬼基因、咖啡因依赖……由真实订单与营养数据推算
- **祖源迁徙路线**：你历年取餐门店构成的"麦门迁徙地图"
- **营养健康风险项**：基于真实营养成分（热量/脂肪/钠/蛋白质）的趣味化提示
- **亲缘鉴定**：输入好友的报告数据，测一测你们是不是"麦门亲兄弟"

### 4. 终端下单 · 程序员的仪式感
为开发者准备的沉浸式 CLI 点餐：
- VSCode / 终端风格的界面，全程键盘操作
- `mcd list` 看菜单、`mcd draw` 抽一张、`mcd order` 下单，一条命令完成选店→选餐→用券→核价→下单
- 所有数据走麦当劳 MCP 真实接口，下单返回真实支付链接

## 安装与配置

### 前置条件
1. 支持 MCP 的 AI 客户端（Trae、Claude Desktop、Cursor 等）
2. 麦当劳 MCP Token（按大赛官方指引领取，见 [MCP_INTEGRATION.md](./MCP_INTEGRATION.md)）

### 配置 MCP
复制 `mcp-config.example.json` 内容到你的客户端 MCP 配置中，并通过环境变量注入 Token：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamableHttp",
      "url": "https://mcp.mcd.cn/mcp-servers/mcd-mcp",
      "headers": {
        "Authorization": "Bearer ${MCD_MCP_TOKEN}"
      }
    }
  }
}
```

> Token 一律通过环境变量 `MCD_MCP_TOKEN` 注入，不要写进任何配置文件或代码。

### 安装 Skill
将 `skill/SKILL.md` 作为自定义 Skill 导入你的 AI 客户端（以 Trae 为例：设置 → Skills → 导入本地 SKILL.md），即可开始对话使用。

## 使用示例

| 你说 | Skill 做什么 |
|---|---|
| 今天吃什么？ | 判断时段 → 查附近门店 → 拉真实菜单 → 抽卡 → 附优惠券和门店 |
| 帮我领券 | 调用 auto-bind-coupons 一键全领 |
| 生成我的麦门年度故事 | 拉历史订单 → 铸徽章图鉴 → 生成年度回顾 HTML |
| 给我一份麦门DNA报告 | 订单+营养+门店足迹 → 生成 DNA 检测报告页 |
| 用终端点餐 | 进入 CLI 模式，命令行完成真实下单 |
